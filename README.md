# Limite Claude atteinte ? Les 5 réglages

Tu vois « limite atteinte, reviens plus tard » trop souvent ? Avant de payer plus cher, change ces **cinq habitudes**. Elles ne donnent pas un abonnement illimité, mais tu tiens beaucoup plus longtemps avec le même.

> Ton usage dépend de la longueur de tes conversations, des fonctions que tu utilises, du modèle choisi et du niveau d'effort. Tout ça puise dans la même limite (Claude web, appli, Claude Code).
> La limite de session se renouvelle toutes les **cinq heures**, à partir de ton premier message. Pour voir où tu en es : **Paramètres > Utilisation**.

---

## 1. Une conversation par sujet

Plus une discussion s'allonge, plus elle consomme de ta limite. Quand tu changes de sujet, ouvre une **nouvelle conversation**. Si tu es déjà près de la limite dans une longue discussion, c'est aussi le conseil d'Anthropic : en commencer une nouvelle.

## 2. Range tes documents dans un Projet

Dépose tes documents de référence dans un **Projet** (section « connaissances ») au lieu de les recoller à chaque fois. Le contenu d'un projet est mis en cache : il compte **moins** dans ta limite quand tu le réutilises. Attention, le cache expire après un moment d'inactivité : au retour d'une longue pause, le premier message compte le contenu en entier.

## 3. Petit modèle pour les questions simples

Le modèle choisi change ta consommation. Les modèles les plus gros consomment plus par message que les petits. Garde le gros pour le travail lourd (analyse, gros projets) et prends un petit modèle (Haiku, Sonnet) pour une question simple, une reformulation, un mail.
Bonus : pour une tâche de routine, baisse le niveau d'effort ou coupe la réflexion approfondie, un effort plus haut consomme plus.

## 4. Coupe les outils que tu n'utilises pas

La recherche web, les connecteurs et les outils sont gourmands : chaque connecteur occupe de la place dans la conversation, et ces outils comptent dans ta limite.
- Désactive les connecteurs inutiles.
- Dans le menu **« + » > Connecteurs > Accès aux outils**, choisis **« À la demande »** : les connecteurs ne se chargent que quand Claude en a besoin (par défaut, c'est « Auto »).
- Si tu n'as pas besoin d'infos récentes, demande à Claude de **ne pas chercher sur le web**.

## 5. Tout dans un seul message

Regroupe tes demandes : plusieurs petites questions à la suite coûtent plus qu'une grande. Donne le contexte d'un coup (ton but, ton public, tes contraintes, le texte entier), pour éviter les allers-retours. Relis ton message avant de l'envoyer.
